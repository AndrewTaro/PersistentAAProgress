# Persistent AA Progress
This modification improves the **Concentrated AA Fire** indicator on the ship state panel.

- The indicator stays on screen while the AA charge is above zero, even with no aircraft in range or AA switched off, so you can see the charge you hold and its decay.
- The indicator fades out, and animates between charging, ready, active and cooldown, like the other state items.
- The countdown number is shown while the effect is active.
- The tooltip shows the current progress, and counts down to when the charge starts to decay.

# Install
1. Download a zip.
2. Unzip the archive and you should get `gui`, `PnFMods` folders, and `PnFModsLoader.py`.
3. Move them to `(wows)/bin/(latest_number)/res_mods/`. So the path will look like `res_mods/PnFModsLoader.py`, etc.
4. Done!
